# Seynur Public Apps Repository  
This repository contains some public apps for Seynur.  

- `restore_archive_for_splunk`: An app for restoring Splunk archives.  
- `splunk_query_runner`: A tool created to automate the execution of Splunk queries.
- `org_frozen_app`: coldToFrozen scripts that archive thawable frozen payload (journal* + optional l2hash) via SCP, S3, or GCS.
- `splunk_es8_config_updater`: This script updates Splunk correlation search stanzas (typically from `savedsearches.conf`) so they are compatible with Splunk Enterprise Security 8.x detection rule requirements.
